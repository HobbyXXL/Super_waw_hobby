## 🚀 Быстрый запуск

### Вариант 1 — Live Server (рекомендуется для VSCode)

1. Установи расширение **Live Server** в VSCode  
   (`Ctrl+Shift+X` → найди `Live Server` от Ritwick Dey → Install)
2. Открой папку проекта в VSCode
3. Нажми **Go Live** в правом нижнем углу  
   *(или ПКМ на `index.html` → "Open with Live Server")*

### Вариант 2 — через терминал

```bash
# Установка зависимостей (только при первом запуске)
npm install

# Запуск
npm start
```

Сайт откроется по адресу: **http://localhost:3000**

### Вариант 3 — просто открыть файл

Открой `index.html` напрямую в браузере *(двойной клик)*  
⚠️ Некоторые браузеры блокируют загрузку JS-модулей из файловой системы.  
Рекомендуется использовать Live Server.

## 📄 Страницы приложения

| Страница | Описание |
|---|---|
| **Авторизация** | Вход / регистрация аккаунта |
| **Онбординг** | Выбор хобби, уровней, целей, первых друзей |
| **Лента** | Главная лента постов с сортировкой по интересам |

| **Друзья** | Список друзей с фильтрацией |
| **Чаты** | Мессенджер с реакциями и набором текста |
| **Настройки** | Тема, язык, имя, аватар |
| **Правила** | Правила сообщества |

## 🎨 Особенности

- 🔥 **Стрик** — ежедневный трекер активности с localStorage
- 📅 **Календарь** — отображение посещений за неделю
- 🔊 **Звуки** — Web Audio API для фидбэка (лайк, сообщение, успех)
- 🌙 **Тёмная тема** — переключается в настройках
- 👀 **Режим гостя** — просмотр ленты без регистрации
- 💬 **Чат с автоответами** — имитация живого диалога

*Проект создан как одностраничное Vue 3 приложение без сборщика (Vite/Webpack).*
